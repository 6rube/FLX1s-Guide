## Aplicaciones de la Comunidad
Estas aplicaciones están adaptadas para el FLX1 y corrigen fallos importantes de las aplicaciones estándar de GNOME y aplicaciones rotas de la tienda de software.

#### Comunicación y social
1. [Phofono](https://gitlab.com/Alaraajavamma/phofono) (SMS/Mensajería/Contactos para reemplazar GNOME Chatty, GNOME Contacts)
#### Utilidades y herramientas
1. [Tweak-FLX1s](https://gitlab.com/Alaraajavamma/tweak-flx1s) (Ajustes de software, control de gestos, más configuraciones)
2. [DebUI](https://gitlab.com/Alaraajavamma/debui) (Interfaz gráfica para el gestor de paquetes Apt)
3. [Bat-mon](https://gitlab.com/Alaraajavamma/flx1s-bat-mon) (Monitor de batería)
4. [FastFLX1](https://gitlab.com/Alaraajavamma/fastflx1) (Pequeños ajustes y correcciones)
5. [speedometer](https://github.com/nico359/speedometer) (Aplicación de velocímetro muy sencilla)
6. [simplesync](https://github.com/nico359/simplesync) (Una herramienta sencilla de sincronización de archivos para servidores Nextcloud y WebDAV, creada con GTK4 y Libadwaita en Rust)
